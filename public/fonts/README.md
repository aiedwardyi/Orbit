# Fonts

## SymbolsNerdFontMono-Regular.woff2

- Source: Nerd Fonts v3.5.1, `NerdFontsSymbolsOnly.zip` from https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1
- File: `SymbolsNerdFontMono-Regular.ttf` from that archive, converted to woff2 with fontTools (`TTFont(...).flavor = "woff2"`). Not subset: the woff2 is 1.2 MB.
- Used only as a glyph fallback in the phone terminal view.

Icon sets carry their own upstream licenses (listed in the release's README): Codicons and Font Awesome CC BY 4.0, Material Design Apache 2.0, Pomicons and Weather Icons OFL 1.1, Font Logos unlicensed, the rest MIT.
